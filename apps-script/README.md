# Google Apps Script для автоматизації обкладинок

Файли в цій папці є версією коду, який потрібно додати до прив’язаного
Apps Script-проєкту Google-таблиці.

## Важливо

- Не вставляйте GitHub token у `Code.gs`, таблицю, README або git commit.
- Не замінюйте наявний код фільтра «Ревізії».
- Додайте `Code.gs` як окремий файл або об’єднайте функції без видалення
  наявних `onOpen`/`onEdit`.
- `onEditCoverAutomation` має бути installable trigger, а не простим `onEdit`.
- Тригери встановлює один визначений адміністратор таблиці.

## Script Properties

У **Project Settings → Script Properties** створіть:

| Property | Value |
| --- | --- |
| `GITHUB_TOKEN` | fine-grained token лише для `library-covers` |
| `GITHUB_OWNER` | `nazarijshvetz1` |
| `GITHUB_REPO` | `library-covers` |
| `COVER_PROCESSING_MODE` | `direct` (без GitHub Actions) |

Для прямого завантаження токену потрібен доступ **Contents: Read and write**
лише до цього репозиторію. Встановіть дату завершення дії токена.

Режим `direct` є стандартним: Apps Script сам знаходить зображення,
конвертує BMP/GIF/JPEG/PNG у JPEG і записує його через GitHub Contents API.
GitHub Actions не потрібні. Резервний старий режим можна ввімкнути значенням
`COVER_PROCESSING_MODE=actions`.

## Перший запуск

1. Додайте код до прив’язаного Apps Script-проєкту.
2. Додайте Script Properties.
3. Запустіть `setupCoverAutomation()` вручну.
4. Підтвердьте запитані Google дозволи.
5. Перевірте, що створено один open trigger, один edit trigger і один clock trigger.

Повторний запуск `setupCoverAutomation()` безпечний: наявні заголовки,
формули й тригери не дублюються.

## Обкладинки для вже наявних матеріалів

Після повторного запуску `setupCoverAutomation()` у таблиці з'явиться меню
**Обкладинки**. Воно працює лише з виділеними рядками аркуша «Матеріали» і
не дозволяє обробити більше 5 матеріалів за один запуск.

1. Виділіть до 5 потрібних рядків.
2. Виберіть **Обкладинки → Знайти для виділених матеріалів**.
3. Дочекайтеся preview і перевірте зображення.
4. Знову виділіть лише правильні рядки.
5. Виберіть **Обкладинки → Зберегти виділені обкладинки**.

CAT-ID береться з колонки A. Джерелом є заповнене поле «Джерело
обкладинки», а якщо воно порожнє — URL з колонки «Електронна версія».
Після успіху оновлюються позначка «Обкладинка», рядок аркуша «Обкладинки»
та всі залежні каталоги й «Ревізія».

Прямий режим обмежує завантаження 8 МБ, HTML — 1,5 МБ, redirects — п'ять,
а HTTP timeout — 20 секунд. Він блокує localhost і приватні IP-адреси.
Apps Script не задає точні 600×900 та JPEG quality 82, тому чинний
`optimize-covers.yml` залишається додатковим оптимізатором після відновлення
GitHub Actions.

## Видалення тригерів

Запустіть:

```javascript
removeCoverAutomationTriggers();
```

Функція видаляє лише тригери цієї автоматизації, створені поточним
користувачем.
